未进行 W 世界标定时，实时 XYZ 与 CSV 默认使用 CAMERA MIDPOINT：
- 原点：左右镜头光学中心的中点（不是相机外壳中点）。
- +X：朝相机前方、远离相机。
- +Y：右相机指向左相机。
- +Z：向上，默认假设两个镜头同高、相机正立且水平安装。
- 单位 mm；界面显示 DEFAULT: CAMERA MIDPOINT 和 +Z assumed up 提示。
  双目标定无法测出整个支架相对重力的共同倾角；严格的水平/竖直坐标请用 W 对齐。

- 已保存并启用的有效 W/相对坐标优先，默认中点不会覆盖它。
  取消 W 保留当前坐标，重启从所选双目标定自动重建默认坐标。
  C→R 更新双目标定后清除旧 W，并重建新相机中点；需要世界坐标时再做 W。
  只置零仍保留当前轴向，不会消除支架倾斜。

快速验收：相机水平正立、左右选择正确时，点位处于左右镜头中间方向应 Y≈0；
向相机前方移动 X 增大，向左相机方向移动 Y 增大，向上移动 Z 增大。
原点高度是镜头中点高度，所以低于镜头的点 Z 为负；地面不一定 Z=0。

工程世界坐标与置零：
1. 已知真实空间 XYZ 的图码在两画面内保持静止，按 W。冻结的是当前图像对，不保存图片/不重复推理。
2. 编辑 runtime/world/reference_points.csv（Windows 自动打开记事本）。
   dictionary / id / feature_type 必须与画面真实编号对应；填实测 XYZ，单位 mm。
   center 是标记中心；corner0..3 是解码后的角点。WORLD TRIAD 的 P0/P1/P2 不能自行当成 ID0/1/2。
3. 保存 CSV，回到 W 窗口按 R。完整对齐至少三点不共线（共面可用），推荐4–6点。
   看残差和红X/绿Y/蓝Z方向；箭头画在第一个参考点表示方向，不一定画在世界原点。
4. U 确认该次拟合的 +Z 物理向上；Enter 保存并启用完整 NPZ（NumPy 多数组归档）。
   N 可输入英文/ASCII 坐标名称，Enter 结束名称输入。OpenCV 窗口标签建议英文；元数据按 Unicode 保存。
   ESC/Q/关闭窗口撤销。重启后应恢复同一坐标名称和文件，不能被新 auto 文件抢占。
5. 如果只想置零/改变参考原点，W 中先按 Z，再 R、Enter。
   只需填写 CSV 第一行，该点映射到你输入的 XYZ（通常0,0,0）；其他模板行可留空。
   当前轴向/尺度保持不变，显示 RELATIVE；置零不能凭空确定重力方向。
6. 世界标定文件保存在 runtime/calibrations/saved/，旧 NPZ 不覆盖。
   P 仍然仅保留副本；W Enter 才明确启用世界文件。C→R重新双目标定会清除W，需要再对齐。
   摄像头索引可能变；实际换相机、左右顺序或移动安装后必须重新核实标定。文件/索引不能证明物理安装没动。

Task002B 新增说明（S 快照 + M 开发者面板）：
- S 键：把"当前这一帧"的左右原始画面 + 已完成的姿态识别结果一次性存成
  一个自包含的诊断文件夹（runtime/diagnostics/snapshots/时间戳/），包含：
  * left_raw.png / right_raw.png       左右原始画面（未标注、未缩放）
  * left_annotated.png / right_annotated.png   带关键点名字 + 置信度的标注图
  * manifest.json    版本化清单：每个关键点的原始观测坐标/置信度都会原样
    保留（包括置信度为 0 的"未检出"占位），可用性用独立字段区分
    （missing/missing_reason 说明为什么不可用，low_confidence 表示检出但
    低于接受阈值）
  * calibration_snapshot.npz    复算所需的标定矩阵（无激活标定时不存在）
  * README.txt          文件说明
- 按 S 不会重新抓帧、不会重新跑 YOLO 推理，保存的正是当前跟踪循环里
  已经拿到的那一对画面和姿态结果，所以不影响实时性。
- 保存过程先写入 .partial 临时目录、全部成功后才改名成正式文件夹；
  如果保存失败不会留下"看似完整的半成品"，也绝不影响历史快照。
- 离线复算（不需要摄像头和模型，只要 NumPy + OpenCV）：
  python tools/inspect_snapshot.py <快照目录>
  会重算矫正坐标和极线误差并与 manifest 里存的值交叉核对：
  退出码 0 = 全部一致；1 = 无法复算（清单/标定缺失或损坏）；
  2 = 复算完成但发现与存储值不一致。

  实测帧率和警告，保持画面干净；按 M 展开后额外显示设备、拒绝计数、
  Stereo RMS / 极线 / 重投影误差、host grab skew、One Euro 参数、
  采集耗时（grab=NNms）和完整热键行。重要警告在收起和展开两种状态下
  都始终显示在最前面，展开面板不会挡住警告。
- 画面上的 fps 是"全流程实测帧率"（抓帧 + 推理 + 三角化 + 发布 + 渲染），
