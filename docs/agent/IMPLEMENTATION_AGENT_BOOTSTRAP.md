# Implementation Agent Bootstrap

Use this text when starting Trae/Harness on this repository:

> Open `CaiKerman/stereo-pose`. Read `AGENTS.md` and `CURRENT_TASK.md` first, then read the instruction referenced by `CURRENT_TASK.md`. Work only on the declared feature branch. Do not modify `main` directly. Run the required tests, commit and push your work, open/update a PR to `main`, and finish by updating `CHANGE_SUMMARY.md`, `TEST_REPORT.md`, and `REVIEW_FOR_OWNERS.md`.

If the current task requires a local reference asset that is not yet present in the repository, obtain it from the owner-provided local package, place it under the reference path specified by the task, and verify any checksum recorded in the repository before using it as baseline evidence.
